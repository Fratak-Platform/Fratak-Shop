# هویت بصری فراتک شاپ در پروژه

منبع اصلی طراحی پوشهٔ [`Visual-Identities/Fratak-Shop`](../Visual-Identities/Fratak-Shop) است (لوگو، نشان، آیکون‌ها، فونت‌ها و
`tokens.css`). این سند می‌گوید آن هویت کجای سایت، پنل مدیریت، فاکتور و PWA اعمال شده و اگر هویت بصری عوض شد چه چیزی را باید به‌روز کرد.

## رنگ‌ها

| نام | کد | کاربرد |
|---|---|---|
| آبی برند | `#0069FD` | دکمه‌ها، لینک‌ها، حالت فعال، بخش «Shop» لوگو (`sky-500` / `blue-500` / `brand`) |
| سرمه‌ای (جوهر) | `#0B1927` | متن پررنگ، نوار کناری پنل، نوار مرورگر و مانیفست PWA، پس‌زمینهٔ حالت تیره (`zinc-900` / `ink`) |
| گرادیان آیکون | `#019BFF → #0156FE` (۱۳۵°) | آیکون اپ و maskable، نوار پایین تصویر اشتراک (`sky-400` و `sky-600`، کلاس آمادهٔ `bg-brand-gradient`) |
| کاغذ | `#FDFDFD` | پس‌زمینهٔ صفحه‌های ساده (تعمیرات، ۴۲۹) |

- **Tailwind** (`src/Fratak-Shop.Web/tailwind.config.js`): پالت‌های `sky` و `blue` با طیف آبی برند و `zinc` با خاکستری مایل به سرمه‌ای
  جایگزین شده‌اند؛ پس صدها کلاس موجود قالب (مثل `bg-sky-500` یا `text-zinc-800`) بدون تغییر نما، رنگ برند گرفتند. برای کد تازه
  کلاس‌های `brand-*`، `ink` و `font-brand` را به کار ببرید. بعد از هر تغییر: `npm run build:css`.
- **هدر باشگاه مشتریان**: گرادیان آبی برند به آبی تیره (`from-sky-500 to-sky-800`).
- **حالت تیرهٔ فروشگاه** (`dark.css`): سطح‌ها طیف سرمه‌ای برند (`#0B1927`، `#102132`، `#13273A`، …) و رنگ‌های تأکیدی آبی روشن برند.
- **پنل مدیریت** (`admin.css`): `--a-primary` آبی برند، نوار کناری سرمه‌ای با نشان برند؛ حالت تیرهٔ پنل هم روی سرمه‌ای ساخته شده.
- **کد سرور**: همهٔ مسیرها و رنگ‌های برند فقط در [`Infrastructure/BrandIdentity.cs`](../src/Fratak-Shop.Web/Infrastructure/BrandIdentity.cs)
  تعریف شده‌اند (پیش‌فرض رنگ نوار مرورگر/اطلاعیه، آیکون‌های مانیفست، تصویر اشتراک‌گذاری و …).
- **تنظیمات**: «رنگ اصلی (PWA و نوار مرورگر)» و «رنگ نوار اطلاعیه» در پنل قابل تغییرند؛ پیش‌فرض هر دو سرمه‌ای برند است. نصب‌هایی که هنوز
  رنگ‌های پیش‌فرض قدیمی قالب را داشتند (`#0ea5e9` / `#0369a1`) در اولین اجرا خودکار به سرمه‌ای منتقل می‌شوند (رنگ انتخابی مدیر دست نمی‌خورد).

### لوگو = آیکون + متن HTML (دور ۱۰)

- نام فروشگاه **داخل تصویر نیست**؛ کنار آیکون با متن واقعی نوشته می‌شود: «فراتک» با رنگ متن و «شاپ» با رنگ تأکیدی (پیش‌فرض آبی `#0069FD`).
  خروجی: `[آیکون] <span>فراتک</span><span class="brand-text-accent" style="color:#0069FD">شاپ</span>` (متن در حالت تیره سفید می‌شود).
- همه چیز از **پنل ← تنظیمات ← برند و لوگو** بدون تغییر کد عوض می‌شود:
  آیکون روشن (`LogoUrl`)، آیکون تیره (`LogoDarkUrl`)، آیکون PWA (`PwaIconUrl`؛ مانیفست، آیکون iOS و پیشنهاد نصب)، دو بخش متن
  (`BrandTextPrimary`، `BrandTextAccent`؛ «-» یعنی بدون بخش دوم)، رنگ متن و رنگ تأکیدی (فقط hex)، و نمایش متن برای هر محل جدا:
  هدر (پیش‌فرض **فقط آیکون**)، ورود/ثبت‌نام، پنل مدیریت و فاکتور (پیش‌فرض آیکون + متن). پیش‌نمایش زنده پایین همان تب است.
- کد: `BrandLockup` و `BrandLockupModel` در `Infrastructure/BrandIdentity.cs`، `ISiteContext.Brand` / `ShowBrandText(place)` و
  partial `Pages/Shared/_BrandLockup.cshtml`. آدرس ناامن (`javascript:`، `//`) و رنگ غیر hex نادیده گرفته می‌شوند و پیش‌فرض برند می‌آید.
- `logo-on-dark.svg` و `mark-on-dark.svg` همان فایل‌های هویت بصری‌اند که مستطیل سرمه‌ای پس‌زمینه‌شان حذف شده (شفاف روی هر زمینهٔ تیره).
  آیکون‌های PWA (مشکی)، badge و تصویر اشتراک از روی SVG های هویت بصری با `@resvg/resvg-js` ساخته شده‌اند
  (منبع آیکون مشکی: `Visual-Identities/Fratak-Shop/svg/app-icon-black.svg`).
- service worker نسخهٔ `v5` شد و آدرس مانیفست `?v=brand3` تا آیکون‌های تازه جایگزین نسخهٔ نصب‌شدهٔ قبلی شوند.

## صفحه‌های بدون قالب

صفحهٔ تعمیرات (`OpsMiddleware`)، صفحهٔ ۴۲۹، ایمیل گزارش‌های زمان‌بندی‌شده و صفحهٔ آفلاین هم رنگ و فونت برند را دارند.

## تست‌ها

- `tests/Fratak-Shop.Tests/Unit/BrandAssetsTests.cs`: وجود همهٔ فایل‌های `BrandIdentity`، اندازهٔ آیکون‌ها، شفاف بودن نسخه‌های تیره،
  برابری رنگ‌های کد با `tokens.css`، ساخته شدن `output.css` با پالت برند و نبودن هیچ ارجاعی به لوگو/فونت/آیکون‌های قالب قدیمی.
- `tests/Fratak-Shop.Tests/Unit/BrandLockupTests.cs`: پیش‌فرض‌ها، مقدارهای اختصاصی، حذف بخش دوم با «-»، رد آدرس/رنگ ناامن و اعتبارسنجی تنظیمات برند.
- smoke test (CI): پاسخ ۲۰۰ فایل‌های برند، مانیفست با آیکون‌های برند و رنگ سرمه‌ای، آیکون بدون متن در صفحهٔ اصلی و آیکون + «شاپ» رنگی در ورود.

## اگر هویت بصری به‌روز شد

1. فایل‌های تازه را در `Visual-Identities/Fratak-Shop` بگذارید.
2. همان‌ها را با همین نام‌ها در `wwwroot/assets/brand` کپی کنید (برای `*-on-dark.svg` مستطیل پس‌زمینه را حذف کنید).
3. اگر رنگ‌ها عوض شد: `tokens.css` ← `BrandIdentity.cs` ← طیف‌های `tailwind.config.js` ← `admin.css` / `dark.css` ← `npm run build:css`
   (تست `BrandAssetsTests` ناهماهنگی را نشان می‌دهد).
4. اگر فونت عوض شد: فایل FD را طبق `assets/font/README.md` دوباره بسازید.
5. `VERSION` در `wwwroot/sw.js` را یک واحد بالا ببرید.
