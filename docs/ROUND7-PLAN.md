# مرحله هفتم – نقشهٔ اجرا و وضعیت

این فایل وضعیت پیاده‌سازی پیشنهادهای تأییدشدهٔ مرحلهٔ هفتم را نگه می‌دارد. هر فاز جداگانه commit می‌شود
و بعد از هر فاز CI (Build + Verify) باید سبز باشد.

قواعد ثابت این مرحله:

- هیچ سرویس پولی و هیچ API هوش مصنوعی خارجی استفاده نمی‌شود. همه‌چیز داخل خود سیستم اجرا می‌شود.
- همهٔ کدهای جدید توضیح فارسی ساده دارند: بالای هر کلاس و متد، و داخل متدها هر جا لازم است (کاربرد، محل استفاده، مثال).
- همهٔ تنظیمات در دیتابیس ذخیره می‌شوند و از پنل مدیریت قابل تغییرند. هر قابلیت حساس یک کلید روشن/خاموش دارد.
