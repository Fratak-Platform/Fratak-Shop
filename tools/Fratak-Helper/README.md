# دستیار محلی فراتک (Fratak-Helper)

اسکریپتی کوچک و رایگان که روی کامپیوتر ویندوزی خودتان اجرا می‌شود و دو کار برای «محتوای هوشمند» سایت انجام می‌دهد:

1. **دریافت صفحه‌های عمومی** (`fetch`): وقتی سایت منبع درخواست‌های هاست اشتراکی را مسدود می‌کند، صفحه را با اینترنت شما می‌خواند.
2. **روان‌سازی متن با مدل زبانی رایگان** (`llm`، اختیاری): اگر [Ollama](https://ollama.com) نصب باشد، متن‌های ساخته‌شده را روان‌تر می‌کند.
   سایت خروجی را فقط وقتی می‌پذیرد که معنی، عددها و طول متن تغییر نکرده باشد.

بدون این دستیار هم همه چیز کار می‌کند؛ این فقط کیفیت و پوشش را بالاتر می‌برد.

## راه‌اندازی

1. در پنل مدیریت: **محتوای هوشمند ← تنظیمات** (`/admin/smart/settings`) ← «ساخت کلید دستیار».
   کلید فقط همین یک بار نمایش داده می‌شود؛ کپی کنید.
2. پوشهٔ `tools\Fratak-Helper` را روی کامپیوتر خود داشته باشید و در PowerShell بزنید:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\Fratak-Helper.ps1
   ```

   کلید را می‌پرسد (هنگام تایپ دیده نمی‌شود). برای اجرای بدون پرسش:

   ```powershell
   $env:FRATAK_HELPER_KEY = "fh_..."
   powershell -ExecutionPolicy Bypass -File .\Fratak-Helper.ps1 -Name "لپ‌تاپ دفتر"
   ```

3. با Ollama (اختیاری): ابتدا `ollama pull qwen2.5:7b` و سپس:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\Fratak-Helper.ps1 -OllamaModel "qwen2.5:7b"
   ```

4. در صفحهٔ تنظیمات «دستیار وصل است» نمایش داده می‌شود. برای توقف: `Ctrl+C`.

| پارامتر | پیش‌فرض | توضیح |
|---|---|---|
| `-Site` | `https://shop.fratak.ir` | آدرس سایت |
| `-Key` | `FRATAK_HELPER_KEY` یا پرسش | کلید دستیار |
| `-Name` | نام کامپیوتر | نامی که در پنل دیده می‌شود |
| `-OllamaUrl` | `http://127.0.0.1:11434` | آدرس Ollama |
| `-OllamaModel` | (خالی = بدون LLM) | نام مدل |

## امنیت

- فقط اتصال **خروجی** از کامپیوتر شما به سایت است؛ هیچ پورتی باز نمی‌شود.
- کلید در سایت فقط به‌صورت هش SHA-256 نگه داشته می‌شود؛ با «ابطال کلید» در پنل، دستیار فوراً قطع می‌شود (خروج با کد ۲).
- فقط آدرس‌های عمومی `http/https` خوانده می‌شوند؛ `localhost`، شبکهٔ داخلی (192.168.x، 10.x، …) و پورت‌های غیرمعمول رد می‌شوند.
  حداکثر ۳ میلیون نویسه و ۲۵ ثانیه برای هر صفحه.
- کلید را جایی منتشر نکنید؛ اگر لو رفت، در پنل کلید تازه بسازید (کلید قبلی باطل می‌شود).
