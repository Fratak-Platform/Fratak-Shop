# مدل دوربری (حذف زمینه) – u2netp.onnx

* **چیست؟** نسخهٔ کوچک (۴٫۵ مگابایت) شبکهٔ U²-Net برای «تشخیص سوژهٔ برجسته» (Salient Object Detection).
  خروجی آن برای هر پیکسل احتمال «جزو سوژه بودن» است و فراتاک با آن عکس کالا/دسته را بدون زمینه می‌کند.
* **منبع:** Xuebin Qin و همکاران، «U²-Net: Going Deeper with Nested U-Structure for Salient Object Detection» –
  https://github.com/xuebinqin/U-2-Net (مجوز **Apache-2.0**). فایل ONNX همان نسخه‌ای است که پروژهٔ rembg (MIT) استفاده می‌کند
  و از بستهٔ npm «@rmbg/model-u2netp» برداشته شده است.
* **SHA-256:** `309c8469258dda742793dce0ebea8e6dd393174f89934733ecc8b14c76f4ddd8`
* **ورودی:** `input.1` با شکل [1, 3, 320, 320] – RGB تقسیم بر ۲۵۵، تقسیم بر بیشینه، کم کردن میانگین و تقسیم بر انحراف معیار ImageNet.
* **خروجی:** اولین خروجی [1, 1, 320, 320] (نقشهٔ نهایی) – بعد از نرمال‌سازی کمینه/بیشینه به بازهٔ ۰ تا ۱.
* **کجا استفاده می‌شود؟** `Infrastructure/Smart/SubjectMatting.cs` (کد اعتبارسنجی ماسک: `Core/Services/Smart/CutoutMask.cs`).
* **هزینه:** حدود ۰٫۴ ثانیه برای هر عکس روی یک هستهٔ CPU؛ بدون اینترنت، بدون سرویس بیرونی و رایگان.

اگر این فایل نباشد، دوربری فقط روی عکس‌های زمینهٔ سفید (روش قدیمی پر کردن از لبه) انجام می‌شود و چیزی خراب نمی‌شود.
