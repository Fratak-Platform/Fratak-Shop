# Fratak-Shop

فروشگاه اینترنتی **فراتک** — یک اپلیکیشن ASP.NET Core (net10.0) با Razor Pages که
فروشگاه (ویترین) و **پنل مدیریت** را در یک پروژه، با معماری لایه‌ای و سئوی کامل ارائه می‌کند.

```
Fratak-Shop.slnx
├─ src/Fratak-Shop.Data     لایه داده: موجودیت‌ها، کانفیگ‌ها، مهاجرت‌ها، بذر‌کارها
├─ src/Fratak-Shop.Core     لایه منطق تجاری: سرویس‌ها، DTO‌ها، موتور سئو
├─ src/Fratak-Shop.Web      لایه وب: Razor Pages فروشگاه + ناحیه پنل مدیریت
└─ tools                    ابزارهای توسعه (Tailwind، تولید مهاجرت)
```

## قابلیت‌های اصلی

| حوزه | توضیح |
| --- | --- |
| فروشگاه | صفحه اصلی، دسته‌بندی، لیست و جزئیات محصول، جستجو، سبد خرید آجاکسی، تسویه‌حساب، مجله (وبلاگ)، نظرات، علاقه‌مندی‌ها، پنل کاربری |
| پنل مدیریت | داشبورد، محصولات، دسته‌بندی‌ها، سفارش‌ها، پرداخت‌ها، کد تخفیف، ارسال، بنر، محتوا، وبلاگ، کاربران و نقش‌ها، پیام‌ها، اعلان‌ها، تنظیمات |
| مرکز سئو | امتیاز محتوا، «سئوی هوشمند»، «هوشمندسازی نوشته‌ها»، سئوی صفحه‌ها، ریدایرکت، خطاهای ۴۰۴، آمار بازدید، نقشه سایت و robots |
| پرداخت | درگاه **سندباکس** (برای تست کامل چرخه خرید) و **کارت به کارت** واقعی: نمایش شماره کارت مدیر → بارگذاری تصویر رسید → تأیید/رد توسط مدیر → اعلان به مشتری |
| نقش‌ها | نقش چندگانه برای هر کاربر: مدیر ارشد، مدیر، مدیر محصولات، مدیر سفارش‌ها، مدیر محتوا و وبلاگ، کارشناس سئو، پشتیبان، مشتری |

## نقش‌ها و دسترسی‌ها

| نقش | دسترسی |
| --- | --- |
| `SuperAdmin` | همه بخش‌ها، تنظیمات و مدیریت نقش‌ها |
| `Admin` | همه بخش‌های عملیاتی به‌جز تنظیمات حساس |
| `ProductManager` | محصولات، دسته‌بندی‌ها، موجودی |
| `OrderManager` | سفارش‌ها، پرداخت‌ها، ارسال |
| `ContentManager` | مقالات، صفحات، دیدگاه‌ها |
| `SeoManager` | مرکز سئو و سئوی محصولات (مشاهده‌ی فقط‌خواندنی محصول) |
| `SupportAgent` | پیام‌ها، دیدگاه‌ها، پیگیری سفارش |
| `Customer` | خرید و پنل کاربری |

هر کاربر می‌تواند **هم‌زمان چند نقش** داشته باشد؛ دسترسی‌ها اجتماع نقش‌ها است
(`UserRole.IsStaff`، `UserRoleExtensions`). سیاست‌های دسترسی در `Web/Infrastructure/PolicyNames.cs`
و فهرست پویای منوی پنل در `Web/Infrastructure/AdminNavigation.cs` تعریف شده‌اند.

## سئو

* هر موجودیت محتوایی (محصول، مقاله، دسته، صفحه) مالک یک `SeoMetaData` است که با
  `OwnsOne(..., "Seo", ...)` ذخیره می‌شود (بیش از ۶۰ فیلد: متا، OG، توییتر، اسکیما، سایت‌مپ).
* `SeoService.Build` از رکورد سئو + یک `SeoFallback` یک `SeoRenderModel` کامل می‌سازد؛
  پس هیچ صفحه‌ای بدون تگ متا رندر نمی‌شود.
* موتور سئو (`Core/SeoEngine`) متن را تحلیل می‌کند: تراکم کلمه کلیدی، ساختار عنوان‌ها،
  طول محتوا، پیوند‌های داخلی و ... و امتیاز ۰ تا ۱۰۰ می‌دهد.
* **سئوی هوشمند**: پیشنهاد فیلدها را در یک رکورد `SeoAuditRecord` ذخیره می‌کند؛
  کارشناس بازبینی و اصلاح می‌کند و فقط پس از تأیید روی محتوا اعمال می‌شود
  (هیچ‌گاه ذخیره خودکار انجام نمی‌شود).
* **هوشمندسازی نوشته‌ها**: پیش‌نویس بهتر توضیحات کوتاه و متن محتوا را برای بازبینی می‌سازد.
* مسیرهای `/sitemap.xml` و `/robots.txt` پویا هستند و `SeoRoutingMiddleware` ریدایرکت‌های
  ۳۰۱/۳۰۲ را اعمال و خطاهای ۴۰۴ را برای تبدیل به ریدایرکت ثبت می‌کند.

## راه‌اندازی

پیش‌نیاز: .NET SDK نسخه ۱۰ و Node.js (برای ساخت CSS).

```bash
# ۱) ساخت فایل استایل (Tailwind)
cd tools/tailwind
npm install
npm run build        # خروجی: src/Fratak-Shop.Web/wwwroot/assets/css/output.css

# ۲) رشته اتصال پایگاه داده در appsettings.json
#    کلید ConnectionDefault (SQL Server)

# ۳) ساخت و اجرای پروژه
cd ../..
dotnet build Fratak-Shop.slnx
dotnet run --project src/Fratak-Shop.Web
```

در اولین اجرا مهاجرت‌ها اعمال می‌شوند و مقادیر پیش‌فرض (تنظیمات سایت، منوها، صفحه‌ها،
سئوی صفحه‌ها و استان‌های کشور) به‌صورت خودکار ساخته می‌شوند.

### ساخت مهاجرت جدید

```bash
dotnet ef migrations add <Name> \
  --project src/Fratak-Shop.Data --startup-project src/Fratak-Shop.Web
```

> راهنمای داخلی: `tools/dev/schema_migration.py` برای تولید مهاجرت بدون ابزار EF موجود است.

## ساختار پنل مدیریت

پنل مدیریت یک **Area** در پروژه Razor Pages است: `src/Fratak-Shop.Web/Areas/Admin`.
آدرس ورود: `/admin`. هر بخش صفحه‌ی مستقل خود را دارد و برای دسترسی‌های ریزتر
(`Products`، `Orders`، `Content`، `Seo`، `Support`، `Settings`) سیاست‌های جدا تعریف شده است.

## نکته امنیتی

پروژه برای اجرای آزمایشی آماده است؛ پیش از انتشار در محیط تولید، مقادیر
`ConnectionDefault`، کلیدهای سرویس پیامک و درگاه پرداخت را از متغیرهای محیطی یا
`appsettings.Production.json` تأمین کنید.
